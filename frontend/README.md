# frontend

学習記録をキャラクターの成長として見せる、静的なフロントエンド（HTML/CSS/JS、フレームワーク不使用）です。

## 使い方

`index.html` をブラウザで直接開くだけで動作します。ローカルサーバーは必須ではありません。

```bash
# ローカルサーバーで開きたい場合（任意）
cd frontend
npx serve .
```

## ファイル

- `index.html` — 現行版（画面A：初期設定 → 画面B：メイン、の2画面構成）
- `sodateru-prototype-v3.html` — `index.html` と同内容
- `sodateru-prototype-v2.html` — 旧版（記録ログ形式、単一画面）
- `sodateru-prototype.html` — 初期プロトタイプ（チェックリスト形式）

## 画面構成（v3〜）

**画面A：はじめの設定**
- キャラクターにする写真を1枚アップロード（画像追加は1つに統合）
- 日割りの分け方を「ページで分ける／単元で分ける」から選択（トグル）
- 選んだ分け方に応じて「合計ページ数」または「合計単元数」、終わらせたい日数を入力
- 「プロジェクトを登録する」を押すと：
  - ページモード … そのまま画面Bへ
  - 単元モード … 単元名を入力するモーダルが開き、各単元に名前をつけてから画面Bへ（空欄は「単元1」などになる。単元数は最大100）

**画面B：メイン画面**
- アップロードした写真をそのまま使ったキャラクター表示
- レベル・経験値バー（Lv1〜Lv50、累計5000XPで到達）
- ページモード … 今日のタスク（復習／本学習）を「やった」ボタンで完了、確認ダイアログあり
- 単元モード … 「単元リスト」を番号の小さい順に表示。各単元を「やった」で完了し、確認ダイアログあり
- Lv50に到達すると「キャラクターを変える」ボタンが解放され、画面Aに戻れる

### 経験値の考え方

- 目標：参考書を最後まで終える頃にLv50へ到達する
- ページモード：総経験値5000を「何日で終わらせるか」で割り、1日あたりの獲得XPを算出（等分割り）。1日のXPは「復習」「本学習」タスクで折半。1日のノルマ量は `合計ページ ÷ 日数` の切り上げ
- 単元モード：総経験値5000を「単元数」で割り、1単元あたりの獲得XPを算出（全単元完了でLv50）
- ページ数が章ごとにバラバラな参考書では「単元で分ける」が使いやすい

## 今後の対応

現状はブラウザのメモリ内だけでデータを保持しており、リロードすると消えます。
`../backend` のAPIと接続すると、記録をサーバー側に保存できるようになります。
